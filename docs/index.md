# SaldoVibe

Självhostad bokföring för svenska företag: BAS-kontoplan, SIE-import/export, momsdeklaration,
löner med AGI-rapportering till Skatteverket och en hash-kedjad, oföränderlig verifikationslogg
enligt Bokföringslagen och BFNAR 2013:2. Byggd i Django, körs på din egen server med Docker.

- [Användarhandbok](user-guide/README.md) – komma igång, löpande bokföring, moms, fakturor, bank, lön, rapporter
- [Drift](ops/README.md) – installation, miljövariabler, backup, uppgraderingar
- [Källkod på GitHub](https://github.com/montegrotto/SaldoVibe) – MIT-licens, buggar rapporteras som issues
