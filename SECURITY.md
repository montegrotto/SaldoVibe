# Säkerhet

SaldoVibe hanterar bokföring, löner och personuppgifter. Hittar du en sårbarhet, rapportera den
privat – inte som ett öppet issue.

**Rapportera via GitHubs privata sårbarhetsrapportering:**
<https://github.com/montegrotto/SaldoVibe/security/advisories/new>

Beskriv gärna vilket flöde som berörs, hur det kan utnyttjas och vilken version/commit du testat mot.
Projektet drivs av en person på fritiden, så räkna med svar inom någon vecka snarare än några
timmar. Rättningar publiceras som vanliga releaser; det finns inga separata säkerhetsversioner av
äldre releaser – uppgradera till senaste.

---

*English:* please report vulnerabilities privately through GitHub's private vulnerability reporting
(link above), not as public issues. Expect a reply within about a week.
